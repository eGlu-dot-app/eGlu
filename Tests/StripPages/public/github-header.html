Light signed-in dashboard

The team keeps its project notes in a shared document. Each note includes the problem, the alternatives considered and the reason for the final choice. During the weekly review, people read the full paragraphs before checking the links and controls at the edge of each section. This text continues across the normal page width.

On a narrow window, navigation can wrap while the background keeps its width. A long article still needs enough room for names, dates and complete sentences. These paragraphs provide ordinary running text between the interactive sections so a browser can treat text and controls separately while scrolling.

After the meeting, the author updates the document with the decisions and any questions that remain. Readers can follow the page from top to bottom, open a related item or use the controls near the heading.
